# CheckPoint 2 - Application Development

Aplicação em HTML, CSS e JavaScript que mostra os atores e atrizes do arquivo `js/dados.js` em cards e permite filtrar pelo nome enquanto o usuário digita.

[Acessar o aplicativo no GitHub Pages](https://snwvlr.github.io/checkpoint-2-application-development/)

## Como executar

Abra o arquivo `index.html` no navegador. As fotos usam os endereços presentes em `js/dados.js` e precisam de conexão com a internet.

## Arquivos

- `index.html`: estrutura da página.
- `css/style.css`: aparência e grade responsiva.
- `js/dados.js`: dados fornecidos para o CheckPoint.
- `js/script.js`: exibição dos cards e busca por nome.
